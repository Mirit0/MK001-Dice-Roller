# MK001 Dice Roller

Roll animated 3D tabletop dice or flip a coin with Capri. Supports D4, D6, D8, D10, D12, D20 and D100 (two percentile dice), with numbered faces, cyberpunk visuals and Natural commentary

- Kind: code
- Made by: Mirit0
- Version: 1.7.7

## How to use

Say or type a command such as:

- `roll a twenty`
- `d20`
- `roll a 20`
- `do a d8`
- `flip a coin`
  Almost anything works

You can roll up to four dice at once, including percentile dice. The dice tumble in a temporary window and land on their selected numbered faces before Capri announces the result. Coin flips settle on heads or tails.
